# Jenkins-WEB

## Project Overview
This project demonstrates GitHub integration with Jenkins using a Freestyle Job.

## Technologies Used
- AWS EC2
- Jenkins
- Git
- GitHub
- Linux
- HTML

## Project Workflow
1. Create an HTML file in GitHub.
2. Configure Jenkins to connect to the GitHub repository.
3. Run the Jenkins build.
4. Verify the build output in Console Output.
